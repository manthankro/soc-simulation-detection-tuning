# Contributing

Contributions should improve reproducibility, defensive value, clarity, or safety.

## Before submitting

- Explain the detection hypothesis and required telemetry.
- Include positive and negative validation cases.
- Document field assumptions, time windows, and known limitations.
- Sanitize all sample data.
- Keep demonstrations confined to synthetic data or an explicitly authorized isolated lab.
- Do not add live exploit automation, credential theft, persistence payloads, or external-target instructions.

## Pull request checklist

- [ ] Documentation updated
- [ ] SPL syntax and field assumptions reviewed
- [ ] Positive and negative test cases described
- [ ] No secrets or personal data
- [ ] Safety boundaries preserved
