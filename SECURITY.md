# Security Policy

## Intended use

This repository is for defensive security education and authorized, isolated lab exercises only. Do not use its material against systems without explicit authorization.

## Reporting a vulnerability

Do not publish secrets, personal data, or exploitable details about third-party systems in public issues. For issues in this lab repository, open a GitHub issue with a minimal reproducible description and sanitized logs. For sensitive reports, contact the repository maintainer privately through a channel they publish.

## Safe handling

- Never commit passwords, API keys, private keys, tokens, or real customer logs.
- Keep vulnerable lab systems isolated.
- Use disposable credentials and snapshots.
- Review scripts and dependencies before execution.
