# Portfolio Evidence Checklist

A strong portfolio demonstrates work performed, not only plans or copied reference material. Replace this checklist with links to your own sanitized evidence.

## Infrastructure
- [ ] Hypervisor network configuration
- [ ] Kali / Ubuntu / Splunk VM overview
- [ ] Splunk receiver and index configuration
- [ ] Forwarder health and ingestion proof

## Detection engineering
- [ ] Raw event examples for every data source
- [ ] SPL screenshots with search time ranges visible
- [ ] Field extraction validation
- [ ] Positive and negative test evidence for D01–D04
- [ ] Lookup configuration and review process
- [ ] Detection version history

## Incident handling
- [ ] Correlated event timeline from your own run
- [ ] Analyst triage notes
- [ ] Containment and recovery evidence
- [ ] Sanitized incident report

## Measurement
- [ ] Baseline dataset and test period
- [ ] TP / FP / FN / TN counts
- [ ] Precision and recall calculations
- [ ] Before/after alert volume
- [ ] Limitations and lessons learned

## Presentation
- [ ] Architecture diagram
- [ ] Short project walkthrough video
- [ ] README screenshots with captions
- [ ] Clear statement of what was personally implemented and measured

Never label planned or illustrative evidence as completed lab work.
