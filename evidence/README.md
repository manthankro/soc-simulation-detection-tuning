# Evidence Directory

Add only evidence you personally generated from your own lab or from the explicitly labelled synthetic dataset.

Suggested structure:
- `screenshots/` — sanitized Splunk searches, dashboards, forwarder status, VM topology
- `events/` — small sanitized event excerpts
- `reports/` — completed validation and incident reports

Do not commit credentials, private keys, tokens, public IPs that expose your environment, personal data, or unredacted production logs. The repository's committed synthetic JSONL data is generated by the scenario script and is explicitly labelled as synthetic.
